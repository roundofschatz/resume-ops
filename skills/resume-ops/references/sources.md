# Sources

Every fact this skill states about the outside world traces to a row here. A rule cites its source by ID in square brackets, like [S16], at the point of use, and `tests/test_sources.py` fails if a cited ID is missing here, if a row here is cited nowhere, or if a row's "Used in" list is wrong.

**Grades.** *First-hand*: the vendor's own documentation, a regulator or a statute (a vendor product page counts as the vendor's own claim). *Study*: stated methods. *Survey*: stated methods but self-reported or observational data; the row says when the publisher sells resume or hiring services. *Guide*: university or professional guidance with no data. *Opinion*: an editorial, cited only where the skill weighs it and decides against it. *Secondary*: a law-firm summary, a press report or a reference work. *Live test*: the skill's own test, described in full in the row.

**Dates.** The date is the source's own date; "undated, read 2026-09-28" means the page shows none. Every quote was read at the source on 2026-09-28, or on the date its row gives. Vendor features change fast: recheck a vendor row before quoting it to a candidate.

**What the skill decides without a source.** Most writing rules (the tells table, bullet shape, the number rules) and working thresholds (8 to 12 postings, the 60% and 30% term tiers, the 15-year line) are the skill's own judgment. The text says so where it matters. They are not listed here.

**Adding a source.** Give it the next free ID in its group, fill every column, cite it where it is used, and run the tests.
