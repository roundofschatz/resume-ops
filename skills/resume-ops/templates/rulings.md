# Rulings: [NAME]

Decisions the candidate has made. **Once a point is ruled, it is settled.** Don't raise it again, don't list it as open, don't ask for confirmation a second time.

- Add each ruling the day it is made, with the date.
- A later ruling that covers an earlier one closes it. Note the reversal under the earlier ruling; never delete it.
- This file holds rulings that belong to this candidate: facts, credit, titles, dates, and personal build preferences. A rule about how every resume should be built goes into the skill instead (SKILL.md, Rulings).
- Memory and chat history can point here. They are never the only copy.

---

## Format

```
### YYYY-MM-DD: [short subject]
**Ruling:** [what was decided, in one or two sentences]
**Kind:** fact | credit | title | target | build preference
**Applies to:** [all resumes / this target / this posting]
```

---

## Facts and credit

Answers to contradictions, what can be named, who gets credit for what, confidential clients.

### YYYY-MM-DD: Example: team size at Northwind
**Ruling:** The team was 6 analysts, not 8. Use 6 everywhere.
**Kind:** fact
**Applies to:** all resumes

## Titles

How each title is written on the page, including the parser-safe form, and the formal title as held, which goes into application and background-check forms.

### YYYY-MM-DD: Example: comma titles
**Ruling:** Write "Senior Analyst, Supply Chain" as "Supply Chain Senior Analyst" (same words, qualifier first, no punctuation) so application forms keep the whole title.
**Formal title (for forms):** Senior Analyst, Supply Chain
**Kind:** title
**Applies to:** all resumes

## Target

### YYYY-MM-DD: Example: target
**Ruling:** Base resume targets operations manager and director roles in food and consumer-goods distribution. Runner-up: supply chain planning.
**Kind:** target
**Applies to:** base resume

## Build preferences

Personal choices about how this candidate's resume reads, inside the skill's rules: the summary they model new ones on, words they always or never use, a section they want left off, how their own practice is named, which of two ventures appears.

### YYYY-MM-DD: Example: summary voice model
**Ruling:** Model the summary on the one from the March resume that got an interview at Harbor Foods. Keep its sentence shapes; drop its "I" and its old year count.
**Kind:** build preference
**Applies to:** all resumes
