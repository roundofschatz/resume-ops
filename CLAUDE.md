# resume-ops: rules for Claude

## Where this repo lives

GitHub is the master copy. Work happens in Claude's cloud sessions, started from Ryan's phone or the desktop app. Ryan's computer only pulls a backup; never work on that copy. If this session is running on Ryan's computer instead of in the cloud, say so before changing anything and offer to move it to the cloud.

## Git

- Commit and push to main when a piece of work is done, with a plain message.
- Push before you stop. Work that isn't pushed is lost when the cloud session ends.
- Big files (video, InDesign, Photoshop, the work corpus, past-job files) live in Google Drive, not git.
- Paths use forward slashes from the repo root. No C:\ paths.
- New repo? Add a line for it to repos.txt in the ops repo, so Ryan's computer backs it up.
